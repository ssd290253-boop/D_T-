Part 1: Sequential Circuit with D Flip-Flop

1.1 Circuit Diagram & Logic Gate Equations

Inputs x and y enter from the left and the output A leaves on the right. Two 2-input XOR gates feed a single positive-edge-triggered D Flip-Flop whose output is A. The present state A is fed back into the second XOR gate.

Gate 1 output (XOR 1): outputs 1 when x and y are unequalG1 = x ⊕ y = x′y + xy′
Gate 2 output / flip-flop input equationDA = A ⊕ (x ⊕ y) = A ⊕ x ⊕ y
Full expanded algebraic formDA = A′x′y + A′xy′ + Ax′y′ + Axy = ∑m(1, 2, 4, 7)
Characteristic & next-state equation: Q(t+1) = DA(t+1) = DA = A ⊕ x ⊕ y = A′x′y + A′xy′ + Ax′y′ + Axy
Circuit outputNo separate output gate exists; the flip-flop state A itself serves as the output.

Step-by-step solution procedure
  1. Identify variables: with 1 flip-flop (A) and 2 external inputs (x, y), list all 8 binary rows from 000 to 111.
  2. Evaluate Gate 1 (x ⊕ y): when xy ∈ {00, 11}, x ⊕ y = 0; when xy ∈ {01, 10}, x ⊕ y = 1.
  3. Evaluate Gate 2 (DA): XOR the result of Gate 1 with the present state A.
  4. Determine next state A(t+1): apply the D flip-flop characteristic equation A(t+1) = DA. Copy the DA column directly into A(t+1).

Part 2: Sequential Circuit with T Flip-Flops

2.1 Circuit Diagram & Logic Gate Equations

Two positive-edge-triggered T flip-flops (A and B), two 2-input AND gates, one external input x and one combinational output y. Both flip-flops share a common Clock and an active-low Reset line.

AND gate 1 (input to flip-flop A)TA = x · B
Direct input to flip-flop BTB = x
AND gate 2 (circuit output)y = A · B
T flip-flop characteristic equation (T = 0: no change · T = 1: toggle)Q(t+1) = T ⊕ Q = T·Q′ + T′·Q
Next state of AA(t+1) = TA ⊕ A = (x·B) ⊕ A = (Bx)′A + (Bx)A′ = AB′ + Ax′ + A′Bx
Next state of BB(t+1) = TB ⊕ B = x ⊕ B = xB′ + x′B

Step-by-step solution procedure
  1. List all combinations: with 2 flip-flops (A, B) and 1 external input (x), write all 2³ = 8 binary rows from 000 to 111.
  2. Calculate flip-flop inputs: set TB = x directly from the input column; set TA = x · B (1 only when x = 1 and B = 1).
  3. Determine next states with the T rule: if T = 0 then no change (NC), Q(t+1) = Q; if T = 1 then toggle, Q(t+1) = Q′.
  4. Calculate the output: y = A · B from the present-state columns (Moore output: equals 1 only in state AB = 11).

Flip-flop action annotations
Set / Reset labels for the D flip-flop; NC (no change) and Toggle labels for the T flip-flop accompany every row of the state tables.
Complete Boolean expansion

Timing & clocking behavior
All state transitions (PS → NS) occur synchronously at the rising (positive) edge of the clock (↑), as shown in the lavender timing waveforms.
